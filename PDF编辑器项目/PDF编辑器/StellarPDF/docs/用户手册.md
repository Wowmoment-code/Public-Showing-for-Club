# 星澜 PDF 使用手册

## 0. 启动

双击工作区根目录的 `星澜PDF.exe`。它是启动器，会调用
`StellarPDF/bin/星澜PDF_主程序.exe` 并把临时目录切换到 `StellarPDF/runtime/temp`，
避免系统临时目录权限问题。

请保持启动器与 `StellarPDF` 文件夹在同一目录。首次启动单文件主程序需要解压运行时，
可能等待几秒。

## 1. 打开文档

- 启动后点击“打开 PDF”，或把 PDF 拖入窗口。
- 也可以从欢迎页的“最近打开”继续上次文档。
- 受密码保护的 PDF 会提示输入打开密码。

## 2. 阅读

- 首页 → 阅读视图：连续阅读、单页、双页、全屏。
- 右下角可缩放、适合宽度、适合页面。
- 左侧缩略图点击跳页；按住 Ctrl/Shift 多选。
- 按 F11 进入全屏，Esc 退出。

## 3. 直接编辑文字

1. 在“编辑”选项卡点击“编辑文字”，或直接双击页面上的文字。
2. 在弹窗中修改内容、字号、颜色、粗体和对齐。
3. 点击“应用修改”。原文字被替换，周围内容不动。
4. Ctrl+Z 可撤销。

对于扫描件，先使用“工具 → OCR 识别”添加文字层。

## 4. 图片与形状

- “插入图片” → 在页面点击放置，支持保持比例。
- 右键已有图片 → 替换图片 / 删除图片。
- “矩形 / 椭圆 / 箭头 / 直线 / 手绘”在页面拖动绘制。
- 选中批注或图片后，按 Delete 删除，右键可编辑。

## 5. 注释与批注

- 选中文本后点击高亮、下划线、删除线或波浪线。
- 区域高亮用于框选整块内容。
- 便签、文本注释会显示在左侧“批注”列表。
- 图章与签名在“注释”或“填写与签署”中。
- “管理批注”可跳转、导出 CSV 或拼合到页面。

## 6. 页面管理

- 左侧缩略图可直接拖动排序。
- 页面选项卡：插入空白页/PDF、删除、复制、移动、旋转、裁剪、页面大小、替换页面。
- 拆分支持每 N 页、每页单独、按范围。
- 合并支持多个 PDF 排序后合并。
- 提取/导出会把选中页面保存成新的 PDF。

## 7. 转换

- PDF 转 Word：保留段落、文字样式与图片。
- PDF 转 Excel：优先识别表格；没有表格时按行输出。
- PDF 转 PPT：每页一张幻灯片。
- PDF 转图片：PNG/JPG/WEBP，可选 DPI。
- PDF 转 HTML：保留可检索的 HTML 文本。
- Office/图片转 PDF：在“其他格式转 PDF”中选择。
- 批量转换可一次处理多个 PDF。

## 8. OCR

1. 工具 → OCR 识别。
2. 选择页面、渲染精度（默认 200 DPI）和输出方式。
3. 可选：
   - 可搜索 PDF（另存为）
   - 仅导出文本
   - 在当前 PDF 中添加隐藏文字层
4. 首次识别需要加载本地模型，请稍候；不会联网。

## 9. 表单与签名

- 填写表单：自动检测已有字段，生成填写界面。
- 添加控件：文本域、复选框、单选、下拉、签名域。
- 表单数据可导出 CSV/JSON。
- 签名支持手写、输入、上传图片；可保存为默认签名重复使用。
- 签名会作为透明图片写入页面。

## 10. 保护

- 加密文档：设置打开密码和权限密码；可选 AES-256/128。
- 权限设置：打印、复制、修改、批注、表单、提取、拼合。
- 解除密码：需要权限密码（所有者密码）。
- 密文涂黑：框选或搜索文字后永久移除。
- 元数据清理、扁平化文档、水印、页眉页脚、页码。

## 11. AI（本地）

- 智能摘要、结构大纲、关键词、全文问答、选中提问、字数统计。
- 全部在本地内存中计算，文档不会上传。
- 不包含在线翻译；如需翻译请复制文字到系统翻译工具。

## 12. 常见问题

**打开后页面显示空白？**
使用“工具 → 修复文档”重新保存，或尝试其他 PDF 阅读器确认文件完整。

**Word 转换后排版乱了？**
复杂多栏、公式、图表无法保证 100% 还原。扫描件请先 OCR，或优先导出图片/HTML 保持版式。

**OCR 很慢？**
首次需要加载模型；后续会复用。降低 DPI 可提速。

**签名有法律效力吗？**
本软件的签名是视觉签名，不包含证书链和可信时间戳。正式电子签名请使用 CA 证书签章系统。
